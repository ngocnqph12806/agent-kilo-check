# SkillSeed — Wireframe UI Flow

> **Bộ wireframe ASCII text-based cho toàn bộ user flow của SkillSeed.**

## Files

- **`ui-flow.md`** — 27 wireframe screens (Part A: Public & Auth, Part B: Onboarding, Part C: Main App, Part D: Admin & B2B) + design tokens

## Cách sử dụng

1. **Figma import:** Copy paste từng wireframe vào Figma frame, dùng font monospace để giữ alignment.
2. **Whimsical:** Paste vào Whimsical wireframe → export PNG.
3. **Excalidraw:** Paste text, sau đó chỉnh sửa shapes.
4. **Hand-off cho designer:** Designer dùng wireframes làm blueprint, tự design high-fidelity version.

## Conventions trong wireframe

- `[ ]` = Button
- `[input]` = Input field
- `( )` = Radio / Checkbox
- `[▼]` = Dropdown
- `→` = Flow direction
- `{ }` = Conditional / dynamic content
- `⚠️` = Required field
- `ℹ️` = Tooltip
- `[Icon]` = Icon button
